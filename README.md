# 대학생이던 내가 이세계에서는 탑을 오르는 용사라고요?!

「대학생이던 내가 이세계에서는 탑을 오르는 용사라고요?!」는 이세계의 탑을 오르며 각 층의 보스에 도전하는 **2D 탑다운 보스 액션 게임**입니다.

서로 다른 공격 패턴을 가진 보스들을 상대로 이동과 대시로 공격을 피하고, 타이밍과 방향을 맞춘 패링으로 반격의 기회를 만들어야 합니다. 보스를 쓰러뜨리고 힘을 얻으며 다음 층에 도전해 보세요!

**[Windows 게임 다운로드](https://github.com/Background0714/BACKGROUND/releases/download/v1.0/BACKGROUND-Windows.zip)** · [릴리스 페이지](https://github.com/Background0714/BACKGROUND/releases/tag/v1.0)

## 실행 방법

플랫폼: Windows 64비트 / 조작: 키보드·마우스

1. 게임 배포 ZIP 파일의 압축을 모두 해제합니다.
2. 압축을 푼 `BACKGROUND` 폴더에서 `TowerPrototype.exe`를 실행합니다.
3. 메인 화면에서 게임을 시작합니다.

| 조작 | 키 |
| --- | --- |
| 이동 | WASD |
| 조준 및 공격 | 마우스 이동 및 좌클릭 |
| 패링·방어 | 우클릭 |
| 대시 | Shift |
| 입장 | Space 또는 E |
| 일시정지 | Esc |
