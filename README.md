# BACKGROUND

UMM Windows x64 | Craft:On P.U.B.G.

탑의 각 층에서 보스의 공격을 피하고, 막고, 반격하는 2D 액션 게임입니다.

**[Windows 게임 다운로드](https://github.com/Background0714/BACKGROUND/releases/download/v1.0/UMM-CraftOn-Windows-x64.zip)** · [릴리스 페이지](https://github.com/Background0714/BACKGROUND/releases/tag/v1.0)

ZIP을 모두 압축 해제한 뒤 `TowerPrototype.exe`를 실행하세요.

| 조작 | 키 |
| --- | --- |
| 이동 | WASD |
| 조준 및 공격 | 마우스 이동 및 좌클릭 |
| 패링·방어 | 우클릭 |
| 대시 | Shift |
| 입장 | Space 또는 E |
| 일시정지 | Esc |

B1 보스 전투는 개발 중입니다.
